# Tidepool

Exploring a distributed trust network of trade: resource-owning nodes exchange useful services and resilience through agents with explicit limits.

## Example case

Read [Distributed trust network of trade](docs/examples/distributed-trust-network-of-trade.md).

The example considers nodes with power, compute, storage, and communications; optional LLM agents; bounded proof of work for admission; evidence of provision; and trust scoped to a resource, quantity, counterparty, and time window.

The proposed first draft uses local resource enforcement and bilateral contracts, with AT Protocol evaluated for identity, discovery, and synchronisation. It does not require a network-wide currency or mining consensus.

**Status:** design draft for discussion, dated 24 October 2026. This repository does not yet contain a running implementation or measured performance results. The example distinguishes proposed choices from guarantees that still need implementation and testing.
